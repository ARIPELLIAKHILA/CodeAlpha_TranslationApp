\# Language Translator Web Application



\## 📌 Project Description



This project is a web-based Language Translator application developed using Python and Flask.



The application allows users to enter text, select a source language and a target language, and translate the text using the `translate` Python library.



This project was developed as part of my CodeAlpha Artificial Intelligence Internship.



\## ✨ Features



\- Translate text between multiple languages

\- Select source and target languages

\- Simple and user-friendly web interface

\- Translate button

\- Clear button

\- Displays translated text

\- Error handling

\- Responsive design 

\## 🛠️ Technologies Used



\- Python

\- Flask

\- HTML

\- CSS

\- translate Python library

## 🌐 Translation Service

The application uses the MyMemory Translation API to perform text translation through an online translation service.

The API is accessed from Python using the `requests` library.
